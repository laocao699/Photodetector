# 光电器件 TCAD 仿真方法学模板 v2（宽禁带/新材料版）

## 1. 固定流程
1. **材料参数先定死**：Eg、χ、εr、Nc/Nv、μn/μp、m*、vsat、掺杂、寿命、温度。
2. **解析 golden 先过门禁**：
   - `n_i = sqrt(Nc*Nv) * exp(-Eg/2kT)`；
   - 肖特基势垒 `ΦB = Wf - χ`；
   - 热发射饱和电流 `J_TE = A*T²*exp(-ΦB/Vt)`；
   - 耗尽宽度 `W = sqrt(2ε(ΦB+Vr)/(qN_D))`。
3. **光学模型独立验证**：
   - Beer-Lambert 或 DUV 吸收表；
   - 能量守恒：∫G·dV ≤ (1-R)·Φ0/hν·A；
   - 对关键波长给出表面光生率。
4. **数值求解**：
   - 轻掺杂/宽禁带材料默认开 extended 精度；
   - 偏压、光强都必须斜坡加载；
   - 二维结构里接触两侧要有区域。
5. **结果必须同时过三层校验**：
   - 解析极限；
   - 物理一致性（KCL、整流方向、截止波长）；
   - 论文 golden 指标（暗电流、PDCR、R、D*）。

## 2. 宽禁带器件特有的坑
- **ni 极小**：不要指望双精度稳态，直接扩展精度。
- **DUV 吸收极浅**：表面/近表面网格要 nm 级。
- **接触主导暗电流**：Dirichlet 与热发射边界在该类器件上可能结果接近，但要按论文暗电流量级显式标定。
- **陷阱/缺陷不可省**：若文献显著依赖陷阱，先实现 SRH/陷阱，再谈绝对值。

## 3. 推荐复用接口
- 材料：`materials/registry.py` + `materials/<material>.py`
- 物理：`physics/wbg_physics.py`
- 几何：`device/<device>.py`
- 驱动：`drivers/a*_*.py`
- 测试：`tests/test_<material>.py`

## 4. 当前 Phase 6A 的可迁移结论
- 已验证 β-Ga₂O₃ 材料库与肖特基/欧姆边界可稳定求解。
- DUV 光生模块可以驱动 255 nm 光电响应，并具有正确的日盲截止。
- 掺杂、厚度、波长的趋势检验应优先于绝对响应度调优。
